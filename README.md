# Girotronica Game Jam 2026

Repositorio preparado para desarrollar una game jam con agentes locales y foco en velocidad. Aun no contiene un proyecto Unity ni fija si el juego sera 2D o 3D.

## Configuracion agentica incluida

- Politica de trabajo: `AGENTS.md`.
- Perfiles locales: `.codex/agents/`.
- Skills locales de jam, Unity, arte 2D y Blender: `.agents/skills/`.
- MCP del repositorio: `.codex/config.toml`.

No se usa OpenSpec ni se exigen tests automatizados. La validacion por defecto es compilacion y smoke playtest del corte afectado.

## Herramientas configuradas

- Unity Relay
- Blender MCP
- PaintBridge para Krita
- Aseprite AI Artist

La configuracion de los agentes y sus procedimientos esta versionada dentro de este repositorio; no depende de perfiles o skills remotos.
